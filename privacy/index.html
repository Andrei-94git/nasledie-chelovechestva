Конфиденциальность

Материалы для редакции

Приём заявок через сайт пока закрыт. Редакция использует полученные сведения для рассмотрения заявки. Email нужен для связи по заявке. При публикации могут быть указаны имя или псевдоним носителя знания и согласованные сведения об источнике.

Хранение и обращения

Данные в браузере

Прогресс уроков хранится в этом браузере и удаляется при очистке данных сайта.

Внешние сервисы

Загрузка встроенного видео начинается после нажатия кнопки, при этом браузер обращается к YouTube. Переход по внешней ссылке открывает сайт соответствующего источника.
