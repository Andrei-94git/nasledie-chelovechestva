Печать через бумажный трафарет

Как перенести простой рисунок на бумагу и получить чёткий край.

Область применения

Трафарет закрывает часть листа. Краска попадает на бумагу только через вырезанное окно и оставляет повторяемый отпечаток. Для первой пробы подходит цельный силуэт листа с плавным краем.

Инструменты и материалы

Подготовьте плотную бумагу для трафарета, пробные листы, малярную ленту, водную краску и круглую кисть с коротким ворсом. Для вырезания взрослому удобно использовать макетный нож и коврик. Для занятия с детьми подготовьте трафарет заранее.

Описание технологии

Наметьте контур и вырежьте окно. Прихватите трафарет лентой по краям, чтобы он прилегал к листу. Наберите немного краски, затем несколько раз коснитесь кистью черновика, пока отпечаток ворса не станет почти сухим.

Лёгкими вертикальными касаниями заполните окно от краёв к середине. Добавьте второй тонкий слой, если цвет получился слишком бледным. Снимите шаблон, подняв его вверх, и дайте оттиску высохнуть на ровной поверхности.

Распространённые ошибки

Избыток краски затекает под край. Боковое движение кисти может приподнять тонкий трафарет. Для повторов подождите, пока край шаблона перестанет мазаться, и проверьте, остался ли он плоским.
